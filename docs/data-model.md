# Data model

No business data model is defined in the foundation phase. Do not infer users, games, rounds, scores, invitations, or their relationships from the project title alone.

Before adding an entity or persistence schema:

1. Register the authoritative source and PRD.
2. Define identifiers, ownership, lifecycle states, invariants, retention, and sensitive fields.
3. Document transactional and concurrency requirements.
4. Map the model to requirements, validation, migrations, and tests.
