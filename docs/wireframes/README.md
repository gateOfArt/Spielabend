# Wireframes

Diese sieben Low-Fidelity-Wireframes sind digital erstellte Seitenskizzen (Rechtecke, Platzhaltertext, keine echte Handschrift oder Foto-Scans). Sie zeigen bewusst nur Struktur und Anordnung, keine finale Gestaltung — Farben, Schriftart und Feinschliff der tatsächlichen Oberfläche weichen ab und sind in `docs/ui-concept.md` beschrieben.

| Datei | Route | Ansicht |
| --- | --- | --- |
| `01-startseite.png` | `/` | Öffentliche Einstiegsseite mit Links zu Registrierung und Anmeldung. |
| `02-registrierung.png` | `/register` | Registrierungsformular (Anzeigename, E-Mail, Passwort). |
| `03-anmeldung.png` | `/login` | Anmeldeformular (E-Mail, Passwort). |
| `04-lobby.png` | `/lobby` | Geschützte Lobby: Navigation, Guthaben-Chip, Logout, Bereichslinks zu Dice/Roulette/Rangliste. |
| `05-dice.png` | `/dice` | Dice-Spielseite: Einsatz, Vorhersage, Ergebnisanzeige. |
| `06-roulette.png` | `/roulette` | Roulette-Spielseite: Einsatz, Farbwahl, Ergebnisanzeige. |
| `07-rangliste.png` | `/leaderboard` | Ranglistentabelle mit Markierung des eigenen Kontos. |

Ein Wireframe legt kein Verhalten fest, solange es nicht im zugehörigen PRD beziehungsweise in `docs/ui-concept.md` übernommen wird.
